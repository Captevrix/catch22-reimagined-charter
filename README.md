# Catch 22 Fishing Charters

I would like to rebuild Catch 22 fishing charters into a modern charter fishing website.  Only use images sourced on the original site.  We should have the same pages - all of them.   We are going to integrate with Vrixplay and highlevel just like we did with our other project reel deal.  Make sure you can see that one for backend stuff.  I do want to still use the video in the hero from the source site.  Source site is https://catch22fishingcharters.com/
